# Portfolio: targets and current mix

Picker reads this file before every pick and updates "Current mix" after each launch. The owner sets the targets (Q 8).

## Targets (proposed)

- At least half of new projects are small-business tools. Owner, 2 November 2026: "small businesses first".
- No two projects in a row come from the same category or serve the same trade.
- Any four projects in a row show each of these at least once:
  - sign-in with saved data;
  - app email;
  - scheduled work;
  - file uploads;
  - a model call with bring-your-own-key.
- Prefer ideas whose customers Marketer can reach: a named community, association or newsletter in `distribution`.
